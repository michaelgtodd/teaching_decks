Best practice

Every loop yields

Put coroutine.yield(), or a wait that yields, in every loop in a command.

A loop that never yields freezes the whole robot. WPILib’s compiler plugin turns a while loop with no yield into a build error.

while (!atTarget()) { drive.arcadeDrive(0.4, 0); }   // build error

 

while (!atTarget()) {

  drive.arcadeDrive(0.4, 0);

  coroutine.yield();                                 // one loop at a time

}

Commands take turns. A command keeps the robot’s only thread until it yields, so a loop with no yield means no other command, trigger or motor safety check runs, and the robot freezes. waitUntil, wait, await and park all yield for you. The WPILib javac plugin checks while loops in coroutine commands and fails the build when one has no yield, which catches the classic v2 mistake at compile time. It checks while loops, so write loops as while loops.
