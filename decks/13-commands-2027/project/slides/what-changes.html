WPILib docs: Commands v3 Programming

3

v3 depends on a Java feature, so C++ and Python teams stay on v2. Both libraries move to new package names, as all of WPILib does in 2027. Motor controllers use setThrottle instead of set, which Deck 2’s 2027 slide mentioned. SendableChooser is gone from the 2027 source, and WPILib’s examples use Selectable instead. Test mode is now called Utility mode, so testInit becomes utilityInit. OpModes are also new in 2027, a way to choose autos and teleops from the Driver Station, but they are optional and beyond this deck.
