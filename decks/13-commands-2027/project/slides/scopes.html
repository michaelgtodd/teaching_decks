WPILib docs: Scopes

18

A trigger binding made inside an autonomous command only exists while that command runs, so an action meant for one routine cannot fire at some other time in the match. A default command set inside a command lasts only as long as that command, then the earlier default comes back. WPILib’s v3 HatchBot example schedules its auto in autonomousInit and notes that it is cancelled automatically when autonomous ends. In v2 the template’s teleopInit had to cancel it.
