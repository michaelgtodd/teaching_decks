5

Read it top to bottom: start the roller, wait until the beam break sees a piece, and the command ends. waitUntil gives control back to the scheduler every loop while it waits, so the drive and everything else keep running. Every v3 command must have a name. The builder will not produce a command until named is called, so a missing name is a compile error, not a blank line in the logs. Whatever stops the roller goes in whenExited, which the next mistake explains.
