This is Deck 2’s table in v3 terms. A parallel group with optional members replaces v2’s deadlineFor: the required command sets the end, and the optional ones are cancelled then. fork starts a child command and carries on without waiting, and the child is cancelled if the parent ends first. awaitAll and awaitAny are the coroutine forms of parallel and race. Groups still need a name, or withAutomaticName, which joins the names of the commands inside.
