Best practice

Default commands get the lowest priority

Give every default command Command.LOWEST_PRIORITY. Raise the priority only for a command that must not be stopped.

A default command’s priority is the lowest that can ever take its mechanism. Set it high, and button commands are discarded.

WPILib’s migration guide warns about this directly: default commands should sit below ordinary commands, and never above 0. Ordinary commands keep the default priority of 0. Use higher priorities rarely and on purpose, and write the reason in a comment, because priorities make it harder to see why a button seems to do nothing.
