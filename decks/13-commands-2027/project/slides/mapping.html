WPILib docs: Migrating from Commands v2

6

Most of the change is vocabulary. A Mechanism is v2’s subsystem, but it is an interface, and it has no periodic method: call update code from robotPeriodic instead. Times in v3 are WPILib units, such as Seconds.of(1). Proxy commands existed in v2 to stop a group from owning every subsystem for its whole length. In v3, a command started with await owns its mechanism only while it runs, which is what proxies did. WPILib’s migration guide has every pair with examples.
