Deck 2’s drive, as a mechanism

KitBotDrive.java

/** Drive from the sticks. Lowest priority, so any other command can take over. */

public Command arcadeDrive(DoubleSupplier fwd, DoubleSupplier rot) {

  return runRepeatedly(() -> drive.arcadeDrive(fwd.getAsDouble(), rot.getAsDouble()))

      .withPriority(Command.LOWEST_PRIORITY)

      .named("Arcade Drive");

}

runRepeatedly is v2’s run. The lowest priority lets any other command take the drive.

This is Deck 2’s driveArcade factory. The suppliers work the same way: the sticks are read again every loop. Robot.java sets it as the drive’s default command, the same as Deck 2. WPILib’s docs advise giving default commands a priority below ordinary commands, because a default command’s priority becomes the lowest priority that can ever take the mechanism.
