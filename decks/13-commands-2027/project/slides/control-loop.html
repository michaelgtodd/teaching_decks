  public Command holdAt(double target) {

    return run(coroutine -> {

1         pid.reset();

          while (true) {

2           double now = angle.getAsDouble();

2           double ff = KG * Math.cos(now); // gravity

3           motor.setVoltage(ff + pid.calculate(now, target));

4           coroutine.yield(); // one 20 ms step

          }

        })

        .whenExited(() -> motor.setVoltage(0.0))

        .named("Arm Hold");

  }

This is Deck 6’s arm loop in v3. Each pass through the while loop is one sample of a discrete-time controller: measure the angle, add the gravity feedforward, add P times the error, apply the voltage, and yield. The yield sets the sample period, 20 ms, and PIDController assumes the same 0.02 s by default, so its I and D terms use the right dt. In v2, the same lines sat inside execute. Here the setup, the loop and the cleanup read in order.
