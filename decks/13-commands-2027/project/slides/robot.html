Deck 2’s bindings and chooser, in v3

Robot.java

public Robot() {

  drive.setDefaultCommand(

      drive.arcadeDrive(

          () -> -MathUtil.applyDeadband(driver.getLeftY(), DEADBAND) * DRIVE_SCALE,

          () -> -MathUtil.applyDeadband(driver.getRightX(), DEADBAND) * TURN_SCALE));

 

  driver.faceDown().onTrue(feeder.intake());

 

  autoChooser.addDefault("Leave and Turn", DriveAutos.leaveAndTurn(drive));

  autoChooser.add("Leave and Turn (steps)", DriveAutos.leaveAndTurnSteps(drive));

  Tunables.publish("Auto", autoChooser);

}

robotPeriodic calls Scheduler.getDefault().run(). autonomousInit schedules the chosen auto.

WPILib’s v3 examples build everything in the Robot class, with no RobotContainer, and this follows them. The drive’s default command and the deadband are Deck 2’s. faceDown is the bottom face button on any gamepad, which is A on an Xbox controller: CommandGamepad names buttons by position, so one class works for any controller. Selectable replaces SendableChooser, and Tunables.publish puts it on the dashboard.
