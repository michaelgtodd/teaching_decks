Step 4: write the command factory

CANDriveSubsystem.java

/** Suppliers, not doubles: the stick is re-read on every 20 ms loop. */

public Command driveArcade(DoubleSupplier forward, DoubleSupplier rotation) {

  return run(() -> drive.arcadeDrive(forward.getAsDouble(), rotation.getAsDouble()))

      .withName("Arcade Drive");

}

run() makes a command that requires this subsystem. Suppliers let it re-read the stick on every loop.

A factory is a method that builds a command. The run helper repeats our lambda every loop, and it adds the subsystem requirement for us, so nothing else can drive at the same time. The parameters are suppliers, not doubles. This method runs once at startup, so a plain double would freeze the stick value forever. A supplier is a little function we can call again for a fresh reading. Building a command does not run it. It has to be bound, which is the next step.
