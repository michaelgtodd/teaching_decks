RobotContainer.java

private void configureBindings() {

  // Sticks read negative when pushed away, and +rotation is counter-clockwise.

  drive.setDefaultCommand(

      drive.driveArcade(

          () -> -MathUtil.applyDeadband(driver.getLeftY(), DEADBAND) * DRIVE_SCALE,

          () -> -MathUtil.applyDeadband(driver.getRightX(), DEADBAND) * TURN_SCALE));

}

Minus signs: match the stick to the robot. Deadband: ignore a stick that rests slightly off zero. Scale: reduce the speed.

Read one line from the inside out. Sticks read negative when pushed away, a leftover from flight simulators, but the robot calls forward positive, so we flip it. Pushing right reads positive, but arcadeDrive calls counter-clockwise positive, so a right push must be negative. That is why both have a minus. Left stick Y drives and right stick X turns: FIRST calls that split-stick arcade. The deadband ignores tiny values near center. The scale limits the top speed. It is the default command, so it runs whenever nothing else needs the drivetrain.
