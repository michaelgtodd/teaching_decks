Five words. A subsystem owns hardware, here the drivetrain and its four motors. A command is one action, like “drive with the sticks”. A trigger says when, like a button press. A default command is what a subsystem does when nothing else wants it. The scheduler runs all of this every 20 milliseconds. Commands do not run while disabled unless you ask them to.
