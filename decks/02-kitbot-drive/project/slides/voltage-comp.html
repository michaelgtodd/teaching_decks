(1.5 min) Simulated, not measured. The model is four CIMs using the numbers in WPILib DCMotor.getCIM, 8.45:1 gearing, 6 inch wheels and an assumed 50 kg robot, with no friction, wheel slip or battery sag. The two battery voltages are examples we picked. Open-loop output follows the battery: half stick on 12.8 volts is 6.4 volts, and on 11.2 volts it is 5.6. Voltage compensation makes half mean 6 volts on either. It does not close the loop: the code still has no idea how fast the robot is going. But the same command now does nearly the same thing, which matters most in autonomous. FIRST’s KitBot code turns it on for this reason.
