Robot.java is mostly boilerplate, and the WPILib docs say to keep it nearly empty. RobotContainer connects everything: it is the one file that references every subsystem and controller. Constants holds numbers with names. Subsystems hold hardware. The template also gives you a commands folder and an example subsystem, which you can delete once you have your own. CANDriveSubsystem is the name FIRST uses in the official KitBot code, so your project will look familiar to other teams.
