Row one: both sides get the same sign but face opposite ways, so the robot rotates. WPILib says it in nearly those words. Row two: two CIMs geared together must turn the same way. If they disagree they push against each other, so current climbs and the gearbox goes nowhere. Stop and fix that. Row three comes straight from the FIRST guide: with the Mode light on, the left stick and D-pad swap. WPILib’s XboxController expects the F310 in XInput mode, which is the X position. Unplug and replug after moving the switch.
