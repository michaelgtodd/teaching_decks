Each line builds one new command out of others, so the results combine too: a sequence can contain a race, and so on. Commands that run at the same time must not require the same subsystem. The PathPlanner app uses the same four group names, sequential, parallel, deadline and race, so an auto drawn in Deck 11 is built from the same pieces.
