Sequences

One command that does three things in order

DriveAutos.java

/** Drive forward, hold still, then turn left: one command that does three things. */

public static Command forwardPauseTurn(CANDriveSubsystem drive) {

  return drive.driveArcade(() -> AUTO_SPEED, () -> 0.0).withTimeout(DRIVE_OUT_SECONDS)

      .andThen(drive.driveArcade(() -> 0.0, () -> 0.0).withTimeout(PAUSE_SECONDS))

      .andThen(drive.driveArcade(() -> 0.0, () -> AUTO_SPEED).withTimeout(TURN_SECONDS));

}

withTimeout ends each step. andThen starts the next step when the one before it ends.

Deck 2 · KitBot drive

16

driveArcade never ends on its own, so withTimeout gives each step an end. andThen builds a sequence: when one step ends, the next one starts, in the same 20 ms loop. The middle step drives at zero, which holds the robot still and keeps the drive updated. Nothing here waits or sleeps. The scheduler keeps looping, reading buttons and updating every subsystem, while this command works through its steps. The method returns one command, so it can be bound to a button or used as an autonomous routine.
