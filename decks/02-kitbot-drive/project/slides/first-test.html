First test

First test: wheels off the ground

1

Prop the robot up

Wheels clear, hands clear. One person ready on Enter (disable). Space is E-stop.

2

Read the SPARK lights

Blue or yellow means brushed. Our code sets brake, so expect blue.

3

Check the controller

Driver Station USB Devices tab: slot 0, and the axes follow the sticks.

4

Enable Teleop and push forward gently

Both sides spin forward at the same speed.

5

Push the right stick right

Left wheels go forward, right wheels go back.

6

Let go, then check

Wheels stop. No red text in Messages. Nothing hot, and no bad smells.

(2 min) Never skip this, even with code that worked yesterday. FIRST’s own guide warns that a robot can move at unexpected speed or in unexpected directions. Use small stick movements. While it runs, the SPARK lights blink green or red with the output. If forward and turning are both backward, you inverted the wrong side, so invert the other one. After an E-stop the roboRIO must reboot before you can enable again, so use Enter for ordinary stops. When this passes, commit to git: now you have a version you know works.
