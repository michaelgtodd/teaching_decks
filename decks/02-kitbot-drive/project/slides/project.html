Project setup

Creating the project and installing REVLib

1

Open the WPILib command palette

Press Ctrl+Shift+P and choose WPILib: Create a new project.

2

Choose Template, Java, Command Robot

The plain one, not the Skeleton: its comments are worth reading.

3

Set the folder, name and team number

Keep it out of OneDrive, then click Generate Project.

4

Install REVLib

Manage Vendor Libraries, then Install new libraries (online), then paste https://software-metadata.revrobotics.com/REVLib-2026.json

5

Build once

Run WPILib: Build Robot Code to prove the library is in.

6

Set up each SPARK in REV Hardware Client 2

Use 2026 firmware (26.x), then set the CAN ID and motor type.

REVLib install

docs.revrobotics.com: Installation

5

OneDrive’s caching interferes with the build. REVLib is needed because the SPARK MAX is a REV product and WPILib does not include its code. The FIRST KitBot guide recommends the offline installer for the robot laptop. The Setup lab has the firmware steps: pick the newest 26.x, even if a newer version is listed.
