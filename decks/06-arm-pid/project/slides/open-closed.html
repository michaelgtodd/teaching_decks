Control theory

Open loop and closed loop

Open loop: no measurement

The code picks an output and sends it.

Nothing measures the result.

A change in battery, friction or load goes uncorrected.

Closed loop: measure and correct

The code sends an output and reads a sensor.

It compares the reading with the target and corrects.

That measurement is called feedback.

Open loop means you pick an output and send it. It works until something changes. Closed loop means you measure the result and correct it, again and again. A robot arm needs closed loop, because battery voltage, friction and game pieces all change.
