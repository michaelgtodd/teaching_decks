Exercise

Tune the arm in the simulator

1.

In Constants.java, set KP to 2 and KD, KG, KV to 0. Run Simulate Robot Code.

2.

Enable, press Y, and watch the arm in AdvantageScope or the sim GUI. It sags.

3.

Follow the tuning steps: set KG, then KV, then raise KP, then add KD.

Done when: Y moves the arm to 45° and it holds within 2°, with no shaking.

28

Setup: in a copy of the examples project, make Robot.java create frc.robot.deck6.RobotContainer, and check that it runs on the keyboard or a gamepad. Change only the gains in Constants: stop the simulator, edit, run again. The Y button runs the move, using the profiled subsystem. Swapping the subsystem for ArmSubsystem in RobotContainer shows the setpoint jump.
