Same inline style as deck 2: the subsystem makes its own commands. moveTo clamps the goal, gets ready, runs the loop, and ends when the arm arrives. Getting ready copies the true angle into the NEO’s encoder, because the soft limits use it and it forgets at power-off. holdPosition keeps the last goal if the arm reached it, and otherwise holds where the arm is right now. Both commands require the arm, so they can never fight each other. If a student asks why moveTo ends: so the default command can take over, which is next.
