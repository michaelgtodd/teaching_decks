A default command that holds, and triggers

RobotContainer.java

private void configureBindings() {

  // With nothing else running, hold still.

  // This also stops the arm jumping when you enable.

  arm.setDefaultCommand(arm.holdPosition());

 

  driver.a().onTrue(arm.moveTo(STOW_RAD));

  driver.y().onTrue(arm.moveTo(SCORE_RAD));

 

  // A Trigger can watch the arm, not just a button.

  // This only fires if the arm has arrived.

  driver.rightBumper().and(arm.atGoal).onTrue(Commands.print("Score!"));

}

The bumper fires only when the driver presses it and the arm has arrived.

The default command runs whenever nothing else needs the arm. If the arm is not at its last goal when you enable, it holds where it is, so it does not jump to an old goal. That is a safety feature, not a nice-to-have. Buttons start moves with onTrue, and each move ends by itself, so the default takes over. The last line is the fun one: a Trigger can watch the arm, and you can combine it with a button using and. Here it just prints, but on a robot that is your shooter or claw.
