Best practice

One unit in Java, convert at the boundary

Pick one unit for all your Java: radians. Convert once, where the code meets the hardware.

The SPARK reports rotations, so ArmUnits is the only class that converts. Hold the arm flat and save the raw reading as ENCODER_FLAT_ROTATIONS.

public static double encoderToArmRad(double encoderRotations) {

  double turnsFromFlat = encoderRotations - ENCODER_FLAT_ROTATIONS;

  return MathUtil.angleModulus(Units.rotationsToRadians(turnsFromFlat));

}

public static double armRadToMotorRotations(double armRad) {

  return Units.radiansToRotations(armRad) * GEAR_RATIO;

}

A unit mistake can drive an arm into its stops. The rule: one unit in Java, converted in one place. The through-bore reports rotations from 0 to 1. Subtract the flat reading, turn it into radians, and angleModulus makes below flat negative. The gear ratio lives here too: the NEO turns 60 times per arm turn. We set no conversion factors on the SPARK, so it reports plain rotations. Wire the through-bore to the data port with the Absolute Encoder Adapter.
