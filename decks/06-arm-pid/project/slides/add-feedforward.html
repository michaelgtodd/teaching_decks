Feedback waits for an error. Feedforward uses what you already know. We know gravity, so we add the holding volts up front and PID never has to fight it. With the same gentle kP 8, the sag is gone: 6.8 degrees down to 0.02. kP did not change. It does overshoot by 5.9 degrees, and that is a job for D and, soon, a profile. It also lets kP stay low.
