Run it

Put a driver on Joystick[0]

1

Drag your device onto Joystick[0]

Drag from System Joysticks to Joysticks. No controller? Use Keyboard 0.

2

Xbox controller: check Map gamepad

It keeps the right stick on axis 4, like the Driver Station.

3

Keyboard: add a right stick

DS menu, Keyboard 0 Settings. Under Axes, set Count to 5.

4

Keyboard: set the keys for Axis 4

Increase is D, Decrease is A. W and S already drive.

5

Click Teleoperated in Robot State

Now push forward.

The code reads joystick 0, so something has to be there. Drag your device onto Joystick[0]. Xbox controller: make sure Map gamepad is ticked. Keyboard: Keyboard 0 comes with W and S, but our code reads turning from axis 4, and the keyboard starts with only three axes. Raise the count to 5, then set keys for Axis 4. Setting a key removes it from its old axis. Then click Teleoperated. If W works but turning doesn’t, the console says joystick axis 4 isn’t available. The docs QR has a picture of this setup.
