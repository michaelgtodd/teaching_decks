Run it

Start the simulator from VS Code

1

Check Desktop Support is on

In build.gradle: includeDesktopSupport = true.

2

Run WPILib: Simulate Robot Code

Press Ctrl+Shift+P and type it. Don’t use the run button by the WPILib logo.

3

Keep Sim GUI selected and press Ok

The Simulation GUI window opens.

4

Find the Robot State window

Its labels work like the Driver Station mode buttons.
