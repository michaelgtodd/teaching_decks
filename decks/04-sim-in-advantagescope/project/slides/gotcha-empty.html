Common mistake

AdvantageScope shows nothing

What you see

The simulator is running, but the field is empty or the title bar says “Searching”.

Why it happens

“Searching” means it hasn’t found the simulator. An empty field means the tab hasn’t been told what to draw.

The fix

Use Connect to Simulator, not Connect to Robot. Then drag SimPose onto Poses.

Check the title bar first. If it says Searching, AdvantageScope hasn’t found the simulator. Make sure you chose Connect to Simulator and that the simulator is still running. It keeps retrying, so it will connect once the code is up. If it’s connected and the field is empty, the tab doesn’t know what to draw, so drag SimPose to Poses. If the timeline looks frozen: scrolling left leaves live time, and scrolling all the way right comes back.
