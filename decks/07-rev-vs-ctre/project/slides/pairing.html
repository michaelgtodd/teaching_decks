This is the slide to photograph. A Talon FX only ever drives the motor it is built into, and the game manual says so too. Talon FXS is the flexible one: Minion, NEO, NEO 550, Vortex with a Solo Adapter, and most brushed motors. NEO 2.0 is not on CTRE’s list. Some teams report it works, but that is forum talk, so bench test first. A Vortex on a SPARK MAX only gets 42 counts per revolution. Remember the KitBot: CIMs are brushed, so kBrushed.
