Deck 7 · REV vs CTRE

11

Both vendors now record logs automatically. REV StatusLogger is new for 2026 and needs no code. CTRE logs every status signal with CAN timestamps, and free users can export key signals like position, velocity and current. Tuner X is ahead on generating code: it can build a full swerve project. That swerve API needs all Phoenix devices. REV gives you template projects instead. Hardware Client 2 is a separate install from the old client. Simulation connects to Deck 4, and both plug into WPILib physics. We ran the REV simulator for Deck 6 but not the CTRE one, so this is not a head-to-head test.
