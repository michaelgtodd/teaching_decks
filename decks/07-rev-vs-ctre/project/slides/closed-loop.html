Deck 7 · REV vs CTRE

6

This is the Deck 6 arm, moved onto the controller. On the roboRIO you wrote ArmFeedforward with kS, kG and kV. Both controllers now have those terms built in. On REV, kG means an elevator, and arms use kCos. On CTRE, one kG and you choose Arm_Cosine. A gain slot is a saved set of gains you can switch between. Watch the units: SPARK kP outputs duty cycle, while a Talon voltage request outputs volts, so the same number means different things. One REV note: firmware 27.0.0 lists a fix for followers running about 1% slow, so test two-motor mechanisms on 26.x. Timing: 2 minutes.
