Best practice

Run the loop on the controller, limit every motor

If timing matters, run the loop on the controller. On every motor, set a current limit.

The controller reads a wired sensor directly, every millisecond. And the 80 A SPARK default is twice the top of REV’s suggested range for a NEO 550, which is 20 A to 40 A.

// SPARK

config.smartCurrentLimit(40);

// Talon FX

config.CurrentLimits.StatorCurrentLimit = 40;

config.CurrentLimits.StatorCurrentLimitEnable = true;

This is true for both vendors. The roboRIO should say where to go, and the controller should do the fast work of getting there. Pick the limit for the motor and the job, not one number for the whole robot. REV publishes suggested ranges, and CTRE suggests finding your stator limit by testing. A limit is also why a stalled intake gets warm instead of dying. Forty amps here is just an example. A real arm may want less, and a drivetrain may want more. Timing: 1 minute.
