The folder you pick is the root of your robot project, the same folder you open in VS Code. Picking a subfolder is a common mistake: the files then end up somewhere deploy does not copy. The first time a project opens in a new season, the app offers to switch to that season’s field and reset the navigation grid. The navigation grid is only used for pathfinding, which this deck does not cover.
