The orange pin on the curve is the marker. Position counts waypoints: 0 is the start, 1 the next waypoint, so 0.5 is partway between them. When the robot passes it, PathPlannerLib schedules the attached command and keeps driving. The app saves a new command name only after you press Enter. When the path ends, PathPlannerLib ends every command its markers started, so a marker command should finish quickly or be fine to stop. spinUp starts the flywheel and ends at once, so the flywheel keeps spinning.
