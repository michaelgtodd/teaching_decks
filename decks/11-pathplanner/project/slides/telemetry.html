PathPlanner docs: Telemetry

28

The telemetry page is in the app’s menu. PathPlannerLib publishes the data whenever a path is running, with no extra code. This image is from the PathPlanner docs and shows an older field. Path inaccuracy is the distance between where the robot should be and where it is, which is the error the follower corrects. A steadily growing error points to a drivetrain problem, such as a wrong trackwidth, slipping wheels or a weak side, not to the path.
