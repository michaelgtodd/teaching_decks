The commands

The two commands the names point to

Launcher.java

/** Starts the flywheel, then ends at once. The flywheel keeps spinning. */

public Command spinUp() {

  return runOnce(() -> flywheel.set(FLYWHEEL_SPEED)).withName("Spin up");

}

 

/** Feeds for LAUNCH_SECONDS, then stops both motors. */

public Command launch() {

  return run(() -> feeder.set(FEED_SPEED))

      .withTimeout(LAUNCH_SECONDS)

      .finallyDo(this::stop)

      .withName("Launch");

}

The launcher is a stand-in with two motors, a flywheel and a feeder. Use your robot’s real mechanism. spinUp sets the flywheel and ends at once, which suits a marker: it ends before the path does, so nothing gets cut off. launch feeds for one second, then stops both motors whether it ends or is cancelled, because of finallyDo. The auto waits for launch to end before Back Off starts.
