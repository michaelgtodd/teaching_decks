The + at the top of the auto’s Sequential Group opens this menu. Every auto is a sequential group, so steps run top to bottom, and each step starts when the one before it ends. The four group types are WPILib’s command groups from Deck 2 and follow the same rules. In a deadline group, the first command is the deadline. A parallel group lets the robot drive a path while an intake runs, for example.
