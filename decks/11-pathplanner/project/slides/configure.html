This runs once. PPLTVController is the follower for differential drives, built on WPILib’s LTV controller. It compares where the trajectory says the robot should be with getPose and adjusts the speeds. The alliance supplier is checked when each path starts, so the same autos work from either side. The last argument makes path commands require the drive.
