The first two are the usual way: draw them in the app and register the names in code. A named command in an auto runs between paths, and the auto moves on only when it ends. A marker command runs alongside the path, so the robot keeps moving. Event triggers bind a command to a marker by its name in Java, and can do more, such as running only while the robot is inside a zone. Java composition skips the app’s auto and builds the routine from paths in code. Use one way per marker, not two.
