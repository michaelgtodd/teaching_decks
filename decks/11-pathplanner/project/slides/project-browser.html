11

Each path is one piece of motion, such as start to hub. An auto strings paths and commands together, so one path can be reused in many autos. The file names match the names on the cards, and robot code loads them by those names, so pick clear names early. New projects get an Example Path, which we deleted. The button at the bottom right manages named commands across the whole project.
