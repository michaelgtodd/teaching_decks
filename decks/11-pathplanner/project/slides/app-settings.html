PathPlanner docs: Settings

8

Settings opens from the menu at the top left. Holonomic mode is on by default, and it is for drivetrains that can move in any direction while facing any way, such as swerve. Turning it off swaps module offsets for a trackwidth and adds a Reversed option to paths. Default constraints are copied into every new path. Start slow and raise them once paths run well. Hot reload pushes path edits to a running robot. The docs ask teams to turn it off at competition, so a stray edit cannot reach the robot.
