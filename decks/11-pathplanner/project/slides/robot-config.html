Mass, MOI and trackwidth match WPILib’s KitBot simulator, so the app agrees with the simulator from Deck 4. MOI, the moment of inertia, measures how hard the robot is to spin. True max drive speed should be measured: drive straight as fast as possible on a full battery. Without a robot, the docs say to use about 85 percent of free speed, here 5.01 m/s. Wheel COF stays at the default 1.2 until you measure it. The current limit matches the code. Bumper sizes only change the drawing. These values are saved to settings.json, and the code reads them.
