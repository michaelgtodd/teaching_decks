Load the settings the app saved

PathPlannerSetup.java

RobotConfig config;

try {

  config = RobotConfig.fromGUISettings(); // deploy/pathplanner/settings.json

} catch (Exception e) {

  DriverStation.reportError("PathPlanner settings: " + e.getMessage(), false);

  return false;

}

fromGUISettings() reads deploy/pathplanner/settings.json: the numbers from the Robot Config slide.

The robot settings live in one place, the app, and the code reads them from the file. If the file is missing, for example because the project was never opened in the app, this reports an error on the Driver Station and returns false instead of crashing the robot code. A crash at startup would leave the robot unable to drive at all. RobotContainer then builds an auto chooser with only None in it.
