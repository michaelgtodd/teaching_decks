Exercise

Run First Auto in the simulator

1.

In a copy of examples, set includeDesktopSupport to true. Make Robot.java create frc.robot.deck11.RobotContainer.

2.

Run WPILib: Simulate Robot Code. In PathPlanner, open Telemetry and choose Simulator.

3.

In Elastic, set Auto Chooser to First Auto. In the Sim GUI, click Autonomous.

4.

In the app, give Drive to Hub its own max acceleration of 1.0 m/s². Restart the simulation and run it again.

Done when: the robot drives to the hub and backs off, with no PathPlanner warnings, and the second run takes longer.

Deck 11 · PathPlanner

29

This uses the Deck 4 simulator through Deck 10’s drivetrain, which simulates the encoders and gyro. Path files deploy to the simulator from src/main/deploy just as they do to a robot. The last task changes one path’s max acceleration in the app: untick Use Default Constraints in Global Constraints first. With hot reload off, restart the simulation to pick up the change. This exercise has not yet been run on a real machine, so check it once before teaching.
