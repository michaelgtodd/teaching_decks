The simulated driving time is about 4.88 seconds, not counting the one-second launch. Reset Odometry tells PathPlannerLib to set the robot’s pose to the start of the first path when the auto begins. That only works if the robot really is placed there, which is Deck 10’s gotcha about start poses. The pin drawn on the first path is the spinUp marker.
