The app never talks to your code directly. It saves plain files into src/main/deploy/pathplanner in your robot project. Deploying copies the deploy folder to the roboRIO, and PathPlannerLib reads the files there. Your code does two jobs: it tells the library how to drive your robot, and it gives every command name in the app a real command. Commit these files to git with the rest of the project.
