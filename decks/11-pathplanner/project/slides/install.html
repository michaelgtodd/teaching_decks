Install

Install the app and the library

1

Install the PathPlanner app

From the Microsoft Store for automatic updates, or from the GitHub releases page.

2

Open WPILib VS Code

Open your robot project.

3

Add PathPlannerLib

WPILib logo in the activity bar, then find PathplannerLib under Available Dependencies and click Install.

4

Build once

Run WPILib: Build Robot Code to prove the library is in.

PathPlannerLib install

pathplanner.dev

Deck 11 · PathPlanner

5

The app and the library are installed separately. The app runs on Windows, macOS and Linux. The GitHub releases page has every platform and any pre-release. The library is a vendor dependency, installed the same way as REVLib in Deck 1. The Dependency Manager offers the version made for this season, 2026.1.2 at the time of writing. The app warns you when the library in your project is older than the app.
