Best practice

Keep an install stick in the toolbox

Put the offline installers on a USB stick before you need them.

Shop Wi-Fi may not cope with 2.4 GB per laptop, and an event may have no internet at all. One mentor downloads once, and every laptop installs from the stick.

WPILib_Windows-2026.2.1.iso                 // WPILib, 2.4 GB

VS Code archive                             // saved by the WPILib installer

ni-frc-2026-game-tools_26.0.0_offline.iso   // Game Tools, 1.39 GB

REV Hardware Client 2, offline firmware     // the "All versions" pack

REVLib-offline-v2026.0.5.zip                // needed in deck 2

Deck 1 · Install and first setup

5

One minute. Mentors, here is the recipe. Run the WPILib installer once online and pick Download VS Code archives to share with other computers. Save that next to the iso. On the NI page, click Install Offline. On the REV download page, get an offline firmware pack, then use Import Pack on the app’s Downloads page. Choose the All versions pack, because the REV slide needs a firmware that is not the newest. The last slide has a QR code for the official offline page. Check the shop Wi-Fi before the workshop.
