Install: Game Tools

Install the FRC Game Tools

1

Find FRC Game Tools 2026 on the NI site

The guide links to it. You need an NI account to log in.

2

Click Download, or Install Offline

Install Offline gives you an .iso for other laptops.

3

Remove older years first

In Add or Remove Programs, uninstall NI Software.

4

Run the installer

From an .iso: mount it, then run install.exe.

5

Leave the Fast Startup screen as it is

Windows Fast Startup can cause problems imaging the roboRIO.

6

Reboot if asked

Then look for Driver Station and the Imaging Tool on the desktop.

Game Tools install guide

docs.wpilib.org: Installing the FRC Game Tools

Deck 1 · Install and first setup

6

One and a half minutes. Game Tools gives you the FRC Driver Station and the roboRIO Imaging Tool, plus the drivers for the roboRIO USB connection. It also installs the mDNS responder that lets your laptop find the robot by name. Uninstalling is only needed when you change years, not for an update within a year. The installer may ask to update .NET Framework: follow the prompts and reboot. If the Mount option is missing, 7-Zip can extract the iso. Mentors, one shared download saves time, since each download needs an NI login.
