Your turn

Enable the robot with the safety checklist

5 min

1.

Lift the robot so the wheels touch nothing. Keep all hands clear of it.

2.

Choose one operator at the laptop, with a mentor beside them. Everyone else stands back.

3.

Check for three green lights and a battery voltage. Choose Teleoperated.

4.

Say “enabling” out loud, then click Enable. Press Enter to disable. Space is the E-stop.

5.

A CAN robot stays still here: this example drives PWM ports. Deck 2 makes it move.

Done when: The robot signal light blinks when enabled and goes solid after Enter.

Deck 1 · Install and first setup

15

Five minutes. Mentors, get one robot imaged, configured and deployed before this session, since the setup takes much longer than five minutes. Practice pressing Enter before you ever click Enable, so it is a habit. Space is the emergency stop, and it works even when Driver Station is not the active window. After an E-stop, you must reboot the roboRIO before enabling again. Use this checklist every time, even when nothing should move, because old code may still be on the robot. If a kid asks why it stays still: the Getting Started code uses PWM, not CAN.
