Common mistake

Update the radio even if WPILib says 1.3.0 is fine

What you see

The WPILib radio page says to skip the update at 1.3.0, so you skip it.

Why it happens

1.3.0 was the 2025 rule. For 2026 events, Vivid-Hosting requires 2.0.0, and the kiosk wants 2.0.1.

The fix

Install 2.0.1 from the firmware page. Then ignore Driver Station ERROR -44021 Radio Version: it is a known bug.

One minute. Anyone reading the WPILib page could fall into this one, so it is not your fault. When two official pages disagree about a product, trust the maker of that product. WPILib’s own Known Issues page agrees with Vivid-Hosting here. Same for the error: it looks scary but does not affect connecting. One more change in 2.0.0: DIP switch 3 no longer turns on 2.4 GHz Wi-Fi. Use the Enable 2.4 GHz Wi-Fi option on the web page instead, even though older pages still mention the switch.
