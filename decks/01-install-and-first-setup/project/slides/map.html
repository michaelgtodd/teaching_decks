Two minutes. Think of setting up a new phone: an operating system, a network connection, then apps. The roboRIO is the computer on the robot, and its image is that operating system. Firmware is software that lives inside a device, like a radio or a motor controller. CAN is the wired network joining the roboRIO to motor controllers, and a CAN ID is each device’s address on it. If a kid asks whether they need both vendor tools: no. REV parts use REV Hardware Client 2 and CTRE parts use Phoenix Tuner X.
