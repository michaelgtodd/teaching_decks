(1.5 min) This is a real run of this deck’s code in the WPILib simulator: an S-curve of about 3 meters, at up to 2 meters per second. “Weak side” means the left side gets 90 percent of its volts, like a stiff gearbox. Green is a healthy robot on feedforward alone. It falls 29 cm behind while speeding up, then catches up. Orange is the same code with the weak side: it ends 81 cm off. Blue adds feedback, and stays within 2 cm. This is a simulator, so a real robot will be messier. Feedback can also only fix what your sensors can see. You will run this yourself soon.
