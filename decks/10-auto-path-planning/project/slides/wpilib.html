(2 min) This is WPILib alone: no vendor library, no app. TrajectoryGenerator takes a start, an end, points to pass through and speed limits. This command follows the result. Read the two middle lines out loud: ask the plan where to be, then ask the follower for speeds. WPILib’s docs say LTV replaced Ramsete, so old tutorials may show that name. PathPlanner’s tank follower is built on this same class. With no app, you type every waypoint. That is a good way to learn, and a slow way to build ten autos. The docs point swerve teams to Choreo or PathPlanner.
