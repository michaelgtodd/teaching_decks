private void follow(DifferentialSample sample) {

  ChassisSpeeds plan = sample.getChassisSpeeds();

  drive.driveSpeeds(follower.calculate(drive.getPose(), sample.getPose(),

      plan.vxMetersPerSecond, plan.omegaRadiansPerSecond));

}

 

public AutoRoutine toHubAndLaunch() {

  AutoRoutine routine = factory.newRoutine("toHubAndLaunch");

  AutoTrajectory toHub = routine.trajectory("toHub"); // deploy/choreo/toHub.traj

  routine.active().onTrue(Commands.sequence(toHub.resetOdometry(), toHub.cmd()));

  toHub.atTime("spinUp").onTrue(Commands.print("spin up")); // a marker from the app

  toHub.done().onTrue(Commands.print("launch fuel here"));

  return routine;

}

The top half is the job PathPlanner does for you. Choreo hands you one sample per loop, and you decide how to follow it. This one uses the same LTV follower as before. We hand this method to an AutoFactory, along with get pose and reset pose. The bottom half is the routine, which is a set of triggers, the same Trigger class you bind buttons with. When the routine starts, reset odometry and run the path. At the spinUp marker, placed in the Choreo app, start the launcher. When the path is done, launch. Install it from the WPILib Dependency Manager too.
