Deck 10 · Auto path planning

7

Every library today needs a pose, and a pose comes from sensors. Encoders measure wheel travel. A gyro measures heading. Odometry combines them into a position on the field. The KitBot uses brushed CIMs, which have no encoder inside, and FIRST’s KitBot guide and code use no encoder or gyro. Tuned means the robot really drives at the speed you ask for. So on a stock KitBot, no path library can work yet. Brushless motors such as NEOs report their own rotation, so they would still need the gyro.
