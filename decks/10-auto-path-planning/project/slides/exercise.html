Deck 10 · Auto path planning

16

(6 min) Mentors, set this up first. In a copy of the examples project, set includeDesktopSupport to true and make Robot.java create frc.robot.deck10.RobotContainer. Students edit only Constants.java. This uses PathPlanner on a simulated KitBot with sensors added, and the path is built in code, so no app is needed. We got about 0.01, then 0.01, then 0.56 meters. If TargetPose appears on the far side of the field, open the FMS window and set Alliance Station to Blue 1. Done early? Change the end point in Constants, and watch the curve change.
