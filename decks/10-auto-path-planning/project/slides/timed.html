Best practice

Start with a timed auto

Get a timed auto working first. It needs no sensors and no library.

FIRST’s KitBot code works this way. This one moved 2.5 m in our simulator, but carpet and battery change that, so measure on a real floor.

public static Command driveForward(CANDriveSubsystem drive) {

  return drive.driveArcade(() -> 0.6, () -> 0.0).withTimeout(1.5)

      .andThen(drive.runOnce(drive::stop))

      .andThen(Commands.print("launch fuel here"));

}

(1.5 min) This is a complete autonomous routine: drive for a set time, stop, then launch. FIRST’s own KitBot code does the same thing with withTimeout, so you already know the tools. It gives you a working auto on day one. The weakness is that time can’t see the floor. Your robot does not know how far it went, so a different carpet or a tired battery changes the result. Keep it short, start from the same spot every match, and test on a real floor. Only move on to paths when your robot can measure itself. Timing cue: about 12 minutes in.
