BLine works differently. There is no trajectory with times in it. It reads the live pose, and PID loops drive toward the next target along straight legs, so it has no feedforward from a plan. Its authors say it tunes quickly, and that is their claim, not ours. It was started by a student on Team 2638, and was announced in January 2026, so it is the newest here. It works only on holonomic drivetrains, which means swerve, so a KitBot can’t use it. It is not in the WPILib vendor list, so you paste a URL to install it. We ran this code against a stand-in, not a real drivetrain.
