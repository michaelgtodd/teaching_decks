Deck 10 · Auto path planning

10

You call configure once, from the drive subsystem or RobotContainer. It needs four things from your code, and you can see them at the top. Those are the same four jobs odometry and wheel control already do. Then you draw paths and autos in the PathPlanner app, and they land in your deploy folder. Install the library from the WPILib Dependency Manager in VS Code. An event marker is a point on a path that runs a command, such as starting the launcher. The command name in the app must match the name you registered. You can also build paths in code, which is what the exercise does.
