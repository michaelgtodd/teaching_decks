The sidebar lists every field. Click an arrow to open a folder. The tab bar picks a view, and the book icon opens the docs offline. Drag a field from the sidebar to Left Axis and watch it scroll. Then click the plus button to add a Table tab for exact values and a Console tab for messages. Clicking a time on the graph selects that time on every tab.
