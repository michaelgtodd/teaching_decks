Epilogue is built into WPILib for Java. Tag a class with @Logged and it generates the logging code when you build. The 2026 Java template already has this set up in build.gradle. By default it sends to NetworkTables, so Level 2 saves it too. Look under Robot, then container, then drive. Each tagged class has to be reachable from Robot. If a kid asks: lots of slow CAN reads can cause loop overruns, so log what you will use. (2 minutes)
