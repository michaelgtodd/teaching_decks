Common mistake

The log is empty or missing

What you see

Failed to open log folder or No files found in folder, or a file with almost nothing in it.

Why it happens

Logging never started, no Driver Station was connected, or Robot Log Path is the wrong folder.

The fix

Call DataLogManager.start(), connect the Driver Station, and match the path to where logs really are.

Three causes, in order. First, nothing is saved unless you start logging. Second, logging pauses after 10 seconds with no Driver Station, and any FRC_TBD file from a run that never connected is deleted the next time the code starts. So a bench test with no Driver Station can leave you nothing. Third, the path. No stick in the robot means your logs are in /home/lvuser/logs, but AdvantageScope looks in /U/logs until you change it.
