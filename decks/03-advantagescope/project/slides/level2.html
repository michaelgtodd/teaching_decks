Level 2: save it to a file

Saving a log with DataLogManager

Robot.java

public Robot() {

  // Save every NetworkTables change to a .wpilog file.

  DataLogManager.start();

 

  // Also record the enabled state and the joysticks.

  DriverStation.startDataLog(DataLogManager.getLog());

 

  // Level 3, next slide: log every @Logged class.

  Epilogue.bind(this);

}

By default the robot saves nothing. These two lines change that. The last line is next.

DataLogManager records every NetworkTables change to a .wpilog file on the robot. So everything from Level 1 is now saved, with no other changes. The second line adds the enabled state and joysticks, which is what lets you line up what the driver did with what the robot did. In a log, your values sit under NT, then SmartDashboard. A log is named FRC_TBD at first, and gets a date once the Driver Station connects. Logging runs on its own thread, so it costs very little.
