Work top to bottom. The AdvantageKit source only listens to AdvantageKit data, so a plain WPILib robot looks empty. If a field exists but its history is missing, that is Live Mode. The default, Low Bandwidth, only fetches a field after you pick it. Logging keeps everything, which is handy on the bench but should not be used when bandwidth is limited, like on a field.
