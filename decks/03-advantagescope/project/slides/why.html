Why a data viewer

Print statements versus a data viewer

Print statements

The robot loop runs 50 times a second, so lines fly past.

You see one number at a time, with no shape to it.

Two values are hard to match up at the same moment.

A data viewer

Every value becomes a line you can read at a glance.

Everything shares one clock, so causes line up with effects.

You can pause, zoom in, and look again after the match.

Deck 3 · AdvantageScope

3

Your robot code runs every 20 milliseconds. That is 50 times a second, so a stutter can come and go before your eyes catch it. Print statements work for a quick check, but the WPILib docs say the console does not scale to rich data. A graph shows the shape of what happened, and it lets you compare two values at the same instant.
