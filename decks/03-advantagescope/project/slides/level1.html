Publishing a value with SmartDashboard

CANDriveSubsystem.java

@Override

public void periodic() {

  // Runs every 20 ms, even while the robot is disabled.

  SmartDashboard.putNumber("Drive/LeftAppliedOutput", leftLeader.getAppliedOutput());

  SmartDashboard.putNumber("Drive/RightAppliedOutput", rightLeader.getAppliedOutput());

  SmartDashboard.putNumber("Drive/BatteryVolts", RobotController.getBatteryVoltage());

}

The key becomes a field. In the sidebar, open SmartDashboard, then Drive.

This is the simplest way out of the robot. SmartDashboard is a small class that writes to NetworkTables, which is how the robot shares values over the network. periodic is the method every subsystem gets, and it runs every 20 milliseconds. Put the unit in the key, like BatteryVolts, and AdvantageScope labels the axis for you. Applied output is a fraction from minus 1 to 1, so it has no unit. This data is live only. Turn off the laptop and it is gone.
