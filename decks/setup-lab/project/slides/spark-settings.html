Job 5: set up the motor controllers

Give each SPARK MAX its settings

1

Give it a CAN ID from 1 to 63

CAN is the wired network to the motors. The ID is its address.

2

Set the motor type

Read the motor: Brushed for CIM, REV NEO Brushless for NEO.

3

Click Persist Parameters

That saves the settings onto the SPARK MAX.

4

Label it with its ID, then do the next one

Every SPARK MAX gets a different ID.

5

Check that they all show up

Power on, USB in any one, then look under CAN Bus.

Think of the CAN ID as a house number: your code uses it to send a message to the right motor controller. Write every ID down, because your code needs the same numbers in Deck 2. Leave the power hub’s ID at its default. Ask a mentor if you are unsure of the motor type, because brushed mode can ruin a NEO. It takes a while, but after the first one the rest go faster.
