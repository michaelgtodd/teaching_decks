SmartDashboard is the Java class that writes to the notebook, and it is the 2026 way to do this. putNumber sends one number. putData sends a whole object with its own widget. Without withName a command shows up as something like RunCommand. Elastic asks for new values about every 60 ms by default, so a dashboard number will not update any faster however often you send it.
