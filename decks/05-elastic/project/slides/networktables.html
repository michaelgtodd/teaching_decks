A dashboard is a program on the laptop that shows what is going on inside the robot. Drivers need a few values during a match, and programmers need many more. Both come through NetworkTables, a set of values hosted by the robot. The robot writes a value and Elastic reads it. You change a value in Elastic and the robot reads that. Each entry has a key, which is its name, and a value. These values are examples. The robot program hosts NetworkTables, so it restarts when the code restarts.
