Keep the layout on the robot

Put the layout file in your deploy folder, so it lives in the repo and on the robot.

Save keeps it inside Elastic on one laptop. Save As writes a .json file you can commit. Download From Robot gives any laptop the same layout.

// In Elastic: File, Save As, into src/main/deploy/elastic-layout.json. Then deploy.

// Elastic's Download From Robot looks on port 5800, so start this once at startup.

private void serveLayout() {

  WebServer.start(5800, Filesystem.getDeployDirectory().getPath());

}

With the layout on the robot, any laptop can connect and press Ctrl+D to load it. Elastic lists every json file in the top of the deploy folder. Overwrite replaces tabs with the same name, and Merge adds new widgets into free space. Open Layout loads a json file from the laptop. One note: Elastic docs still say Export Layout, but the 2026.1.1 menu says Save As.
