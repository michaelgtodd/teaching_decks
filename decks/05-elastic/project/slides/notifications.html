These two extras are what teams like most. They need one file, Elastic.java, from the elasticlib folder of Elastic’s repo. Elastic docs suggest a folder called util, and you may need to change the package line at the top. Our own helper, once, wraps runOnce with ignoringDisable so it also works while disabled. The tab names here are the two Elastic starts with, and they must match yours exactly. These work only in Elastic. Timing: one minute. If a kid asks: withNoAutoDismiss keeps a popup on screen.
