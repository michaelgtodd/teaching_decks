Every team needs this. A chooser is a list of commands with names. Robot.java calls getAutonomousCommand when auto starts, so the pick is read at the last moment. If you read getSelected in a constructor, you only ever get the default. In Elastic this appears as a ComboBox Chooser. A green check means the robot has your pick. A red exclamation mark means it does not. Elastic re-sends your pick after a code restart.
