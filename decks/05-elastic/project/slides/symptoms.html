Run down these quickly and point out that the first two look alike. putNumber writes every time it runs, while setDefaultNumber writes only into an empty box. Neither saves a typed value through a code restart, because Elastic does not send it back. The KitBot guide gives the fix: put a value you like into Constants. Advanced teams can use setPersistent, but then putNumber at startup would still overwrite it. The chooser bug is fixed in Elastic 2026.1.2, which WPILib 2026.2.1 does not install. Timing: 90 seconds.
