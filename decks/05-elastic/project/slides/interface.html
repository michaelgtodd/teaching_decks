Open the real app now and walk through this. It starts with two empty tabs, Teleoperated and Autonomous. Click Add Widget, expand SmartDashboard, then click and drag each value onto the grid. Those are the KitBot guide steps. Green outline means it fits, red means it does not. Drag an edge to resize. Right-click, Show As, to change the type. The Layouts tab in that dialog has List Layout, for grouping tiles. Lock Layout stops widgets moving, and you can still use them. Timing: three minutes, live.
