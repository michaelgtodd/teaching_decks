Getting started

Open Elastic and connect it to the robot

1

Open Elastic

Driver Station gear tab: set Dashboard Type to Elastic. Or VS Code: WPILib logo, Start Tool, Elastic.

2

Open the network settings

Click Settings, then the Network tab.

3

At a robot with the Driver Station running

Set IP Address Mode to Driver Station. This is the default.

4

Without the Driver Station, or in simulation

Team Number (10.TE.AM.2) with your Team Number, or localhost (127.0.0.1) for the simulator.

5

Check the bottom of the window

Network Tables: Connected means Elastic has reached the robot.

4

Two ways to open it. The KitBot guide uses the Dashboard Type dropdown on the Driver Station gear tab, and then Elastic opens with the Driver Station. WPILib docs use VS Code: press Ctrl+Shift+P or click the WPILib logo, choose Start Tool, then Elastic. Driver Station mode is the easiest, because Elastic asks the Driver Station where the robot is. Ctrl+K and Ctrl+Shift+K are shortcuts for robot and simulator. If your Driver Station does not list Elastic, use Start Tool.
