Deck 8 · Understanding motors

3

Voltage sets how fast the motor spins. Current sets how much torque it makes. A spinning motor is also a generator, so it produces a voltage against the battery, called back-EMF. A stopped motor has no back-EMF, so a lot of current flows. As speed climbs, back-EMF grows and current falls. That loop is real feedback, built into the physics.
