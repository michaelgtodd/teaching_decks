Common mistake

The build fails with cannot find symbol

What you see

error: cannot find symbol, pointing at Commands, then BUILD FAILED.

Why it happens

Java only knows a class if the file imports it, and this file has no import for Commands.

The fix

Add the import at the top of the file. The first error names the file and the line.

RobotContainer.java:37: error: cannot find symbol

        .onTrue(Commands.print("Hello, robot"));

                ^

  symbol:   variable Commands

Deck 1 · Your first robot program

12

This is the compiler output when the import is missing. The line number depends on the file. VS Code underlines the word in red before you build, and pressing Ctrl+. on it offers to add the import. A missing semicolon gives the error “’;’ expected”, with an arrow at the spot. When a build prints several errors, fix the first one and build again, because later errors often come from the first.
