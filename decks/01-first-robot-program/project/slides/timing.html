This data is from a WPILib simulation of this deck’s code, with the button changed at 33 and 93 milliseconds. A digital control loop only reads its inputs at each tick, and the time between ticks is called the sample time. The output changes on the first loop after the button changes, so the program is at most 20 milliseconds late. On a robot, the connection from Driver Station and the CAN bus add a little more. set(0.3) asks for 30 percent of battery voltage. Nothing measures what the roller does, which is called open loop. Deck 2 covers it, and Deck 6 closes the loop with a sensor.
