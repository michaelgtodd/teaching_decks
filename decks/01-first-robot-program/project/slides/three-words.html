Part 1: meet the robot

Three words you will use all day

Build

Your laptop checks your code and gets it ready.

Deploy

Your laptop sends the code to the robot.

Enable

You tell the robot it may run your code.

Deck 1 · Your first robot program

6

Think about an app on a phone. Build is finishing the app. Deploy is installing it on the phone. Enable is tapping it to start. They always go in that order. Say each word out loud together, because you will hear them all day. A robot that is not enabled will not move, even with code on it. That is a safety feature. Timing: 2 minutes.
