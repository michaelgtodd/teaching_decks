The simulator runs your program on the laptop, with no robot. Use the command palette entry: WPILib warns that the run button beside its logo does not set up simulation properly. Until a controller is on port 0, the terminal repeats a warning that button 1 on port 0 is not available. Most commands do not run while disabled, so Robot State goes on Teleoperated, although Commands.print is an exception. Keyboard 0 maps Z, X, C and V to buttons 1 to 4, and an Xbox controller’s A, B, X and Y are buttons 1 to 4. Keys go to the window with focus. The message prints once per press, even with the key held, because onTrue schedules only when the button changes.
