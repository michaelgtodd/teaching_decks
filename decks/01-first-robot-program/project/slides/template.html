WPILib docs: Structuring a Command-Based Robot Project

8

This is WPILib’s standard structure, and every project in these decks follows it. WPILib recommends declaring subsystems as private fields in RobotContainer, and that is also where button bindings go. It also says that large amounts of robot code in Robot.java work against the declarative design. The template creates ExampleSubsystem, ExampleCommand and Autos to show the pattern. They do not touch any hardware, so they can stay for now.
