One binding in RobotContainer

RobotContainer.java

private void configureBindings() {

  // Schedule `ExampleCommand` when `exampleCondition` changes to `true`

  new Trigger(m_exampleSubsystem::exampleCondition)

      .onTrue(new ExampleCommand(m_exampleSubsystem));

 

  // Schedule `exampleMethodCommand` when the Xbox controller's B button is pressed,

  // cancelling on release.

  m_driverController.b().whileTrue(m_exampleSubsystem.exampleMethodCommand());

 

  // Print a message when the A button is pressed.

  m_driverController.a()

      .onTrue(Commands.print("Hello, robot"));

}

Add import edu.wpi.first.wpilibj2.command.Commands; at the top of the file. .a() is a Trigger for the A button, and onTrue schedules the command once per press.

WPILib docs: Binding Commands to Triggers

10

configureBindings is where the template sets up triggers, and its first two bindings are WPILib’s examples. m_driverController is the Xbox controller the template created on port 0. The method a returns a Trigger for the A button. onTrue binds a command to that trigger. Commands.print is one of WPILib’s ready-made commands: it prints a string and ends immediately. The binding is declared once, when the program starts.
