Best practice

Give every number a name in Constants

Put CAN IDs and speeds in Constants.java, not in the middle of the code.

The template includes this class for robot-wide constants. Add this inside it, and set kMotorId to the CAN ID of your SPARK MAX.

public static class RollerConstants {

  // The feeder roller on the 2026 KitBot. Must match REV Hardware Client 2.

  public static final int kMotorId = 6;

 

  // Output from -1 to 1. 0.3 is 30% of battery voltage.

  public static final double kSpeed = 0.3;

}

WPILib says constants should be public static final, so they are visible everywhere and cannot change. It also recommends a static import of the inner class, so other files can write kMotorId. The next slide does that. The k prefix is WPILib’s naming style for constants. A value then changes in one place, and its name says what it means. Motor ID 6 is the feeder roller in FIRST’s 2026 KitBot code. Any one motor that can spin freely works, as long as the ID matches the one set in REV Hardware Client 2.
