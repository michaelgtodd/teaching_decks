Deck 1 · Your first robot program

10

Remember the three words: this is build. Your laptop checks the code and gets it ready. No robot is needed for this step. Lots of text will scroll past, and you do not need to read it. You only need the words Build Successful at the end. If you see red text instead, raise your hand. Mentors, give each laptop time to finish before moving on, because every student can win this one.
