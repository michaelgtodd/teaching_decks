Creating a project from the Command Robot template

In 2026 WPILib VS Code, press Ctrl+Shift+P, type WPILib and choose Create a new project. Fill in the form, click Generate Project, open the project, and click Yes I trust the authors.

Ctrl+Shift+P opens the command palette, and every WPILib command starts with WPILib. WPILib’s own walkthrough picks the Getting Started example here. This deck picks the Command Robot template, because every deck in this course is command-based. The team number is how the laptop finds the robot when deploying. WPILib warns that projects on OneDrive are not supported, because its caching interferes with the build. The simulator needs Desktop Support.
