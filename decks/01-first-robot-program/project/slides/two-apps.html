Only two apps today. VS Code is where code gets written. Driver Station is how you start and stop the robot, a bit like the key and the brake in a car. You will see the names WPILib and Java a lot. WPILib is a toolkit that does the hard parts of talking to the robot. Java is the language we write in. If a kid asks about other apps: we will meet those later. Timing: 2 minutes.
