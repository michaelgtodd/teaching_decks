WPILib’s docs recommend private hardware: outside code uses robot actions, not devices. The two () -> pieces are lambdas: code passed to a method to run later. WPILib’s docs say interrupted where this slide says canceled, for the same event. startEnd also makes the command require this subsystem. set takes a value from -1 to 1. A NEO would be kBrushless, and REV warns that brushed mode can permanently damage a NEO.
