Part 1: meet the robot

Make your first project

1

Press Ctrl+Shift+P, then type WPILib

Choose Create a new project.

2

Choose Example, Java, Getting Started

That is a small ready-made program.

3

Pick a folder outside OneDrive

Name your project and tick Create a New Folder.

4

Type your team number

This is how your laptop finds the robot.

5

Click Generate Project, then open it

If asked whether you trust the authors, say yes.
