Exercise

Turn the robot on safely

1.

Check: wheels off the ground, hands clear.

2.

One person at the laptop. Everyone else stands back.

3.

Choose Teleoperated, say “enabling” out loud, then click Enable.

4.

Watch the robot signal light blink, then press Enter.

Done when: The light blinks when enabled and goes solid after Enter. Nothing spins: this code is not set up for these motors.

Nothing will spin, because this code is not set up for these motors. A blinking robot signal light means the robot is enabled. Teleoperated means driver control. Saying “enabling” warns everyone nearby. Use this checklist every time, because old code may still be on the robot.
