WPILib docs: What is WPILib?

3

WPILib is a library: ready-made Java classes for the control system, including sensors, motor controllers and the Driver Station. Code is not compiled on the robot. Your laptop builds it, which WPILib calls cross-compilation, and then deploys it to the roboRIO. The roboRIO runs the program. Driver Station stays connected to enable the robot and to send controller input. The SPARK MAX is a motor controller on the CAN bus.
