Best practice

Learn the stop keys first

Find the stop keys before you ever enable a robot.

Enter disables the robot. Space is the emergency stop. Put a finger on Enter and press it three times, so your hand knows where it is.

Deck 1 · Your first robot program

We do this before anyone enables, and with the robot still disabled. Enter stops the robot and lets you start it again. Space is the emergency stop. It works even if you clicked on another window. After an emergency stop, the roboRIO has to reboot before the robot can run again, so use Enter unless it is an emergency. Timing: 3 minutes.
