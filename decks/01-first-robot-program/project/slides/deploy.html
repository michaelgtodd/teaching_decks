Deck 1 · Your first robot program

21

The SPARK MAX must already have its CAN ID and motor type set, which is Job 5 of the Setup lab. The team number in the project is how VS Code finds the robot. WPILib warns against powering off during a deploy: interrupting it can corrupt the roboRIO filesystem, and the roboRIO then needs re-imaging. After a successful deploy, RioLog opens with the program’s console output, and the program stays on the roboRIO until the next deploy.
