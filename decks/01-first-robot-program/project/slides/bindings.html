BindingWhen the button is pressedWhen it is released
onTrueSchedules the commandNothing: the command runs until it ends
whileTrueSchedules the commandCancels the command
toggleOnTrueSchedules it, or cancels it if runningNothing

Commands.print ends by itself, so onTrue suits it. A startEnd command never ends by itself, so it needs whileTrue.

WPILib docs: Binding Commands to Triggers

18

A startEnd command has no end condition. Bound with onTrue, this motor would keep spinning after the button was released, until the robot was disabled. With whileTrue, releasing the button cancels the command, and canceling runs its second lambda, which sets the motor to 0. WPILib does not recommend toggles for driver control, because the driver has to keep track of the robot state.
