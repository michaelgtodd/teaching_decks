Best practice

Learn the loop in Java, then move it

Get a new loop right on the roboRIO, then move it to the controller.

Java loops are easy to log, change and try in the simulator. A controller loop is quicker and fresher, but its gains use other units, so you tune it again.

(1 min) This is about learning order, not about which is better. REV’s docs recommend doing as much as you can on the motor controller, and for a fast mechanism like a shooter wheel you will want that. But while you are learning, seeing the loop matters more. In Java you can log every term and break it safely in the simulator, as you just did. Once you understand it, move it. Think of training wheels: useful first, and you take them off on purpose.
