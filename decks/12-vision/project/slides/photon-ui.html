Calibrating means showing the camera a printed pattern so PhotonVision can measure its lens. Pose estimation needs it. Then set the pipeline to 3D and turn on multi-target estimation. The coprocessor also needs the right field layout: PhotonVision ships with the welded 2026 layout. Without multi-tag turned on here, the multi-tag method in your code returns nothing and the code falls back to one tag. You open this page in a browser on the robot network, at port 5800.
