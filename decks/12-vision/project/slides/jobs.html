What vision does

Three jobs a camera does on an FRC robot

Find the robot’s pose

Work out the robot’s pose from AprilTags, and use it to correct odometry. The main use in 2026.

Aim at a tag

Turn until a tag sits in the middle of the image. No calibration needed.

Find game pieces

A neural network draws a box around each FUEL it sees. Needs extra hardware.

WPILib docs: What Are AprilTags?

4

The first job is the one most of this deck covers. The second is simpler: WPILib’s docs call it 2D alignment, and it only needs the tag’s position in the image. The third is object detection. A neural network is a program trained on example images. PhotonVision ships a model that detects FUEL, the 2026 game piece, and runs it on an Orange Pi 5 or a Rubik Pi 3. A Limelight 4 runs detection faster with a Hailo-8 accelerator, sold separately. In our count of team code, game-piece detection calls were rare, in about 2 percent of repos.
