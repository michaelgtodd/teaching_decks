This follows the Java example on Limelight’s MegaTag2 page. MegaTag2 assumes your code knows the heading, from a gyro, and uses it to give a good pose from even one tag. The 360 degrees per second check comes from that example. The huge third number means vision never changes the heading: the gyro keeps it. LimelightHelpers is one Java file you copy into your project from Limelight’s GitHub releases. This version returns null when no Limelight is on the network, so check for null. Set the camera’s position on the robot and upload the field map in the Limelight web UI.
