Every new frame

All frames since the last loop, oldest first, so none are skipped.

2

All tags, then one

Multi-tag uses every visible tag. If it is empty, use the clearest single tag.

3

How much to trust it

More for many close tags, less for one far tag, or skip it.

4

When, not now

The time the frame was taken, already on the robot’s clock.

This follows PhotonVision’s own pose example. The PhotonPoseEstimator is built with two things: the field layout, and a Transform3d that says where the camera sits on the robot. Each method name is a strategy. PhotonVision’s docs recommend coprocessor multi-tag for all teams, with a single-tag fallback. Ambiguity means a tag that could be seen from two different places, as WPILib’s AprilTag page explains, so the lowest-ambiguity tag is the clearest. Install PhotonLib from the WPILib Dependency Manager. Its version must match the PhotonVision version on your coprocessor.
