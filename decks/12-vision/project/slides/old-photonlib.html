Most PhotonVision tutorials and many team repos were written before 2026. In PhotonLib 2026, the constructor that takes a PoseStrategy and the update method are marked deprecated for removal. Your code still builds, with warnings, but a later release can delete them. The 2026 way is the two-argument constructor, then calling the method for the strategy you want. Even PhotonVision’s own multi-tag page still names the old strategy, so trust the Javadoc and the example code over older prose.
