We read the files of 925 public Java robot projects from the 2026 season. In the code, Limelight and PhotonVision are about even, and 39 percent have no camera code. PhotonLib is in far more repos than use it, because templates include it. AdvantageKit’s vision template runs Limelight on the robot and PhotonVision only in simulation. 52 repos use PhotonVision only that way. 56 repos use both. Private repos are missing, and template code still counts. We found no 2026 poll with results.
