Stock KitBot: fix odometry first, because a camera pose corrects an estimate you already have. Then, if you can get a Limelight 4, it has the fewest parts and the least setup, and many teams use it. If not, PhotonVision is free software and equally common in our count, and simulation is built in. Before buying anything, learn the code in simulation. The drivetrain code is the same either way, so you can change cameras later. QuestNav is newer and less common, in 3 percent of repos.
