Three more options teams use

PhotonVision on a Limelight

PhotonVision publishes images for Limelight 2, 2+, 3, 3G and 4. Your code then uses PhotonLib.

QuestNav

A Meta Quest headset tracks its own motion with cameras and an IMU. Reset it at a known spot.

WPILib on the roboRIO

AprilTagDetector runs inside your robot program, on a USB camera. No coprocessor.

Flashing means replacing a device’s operating system. PhotonVision’s install page has an image for each Limelight model, so a team with a Limelight can switch software. In our count, 29 (3%) repos create a QuestNav object, and most of those also use a camera. Its docs say AprilTag tracking is experimental, on a separate branch. WPILib’s own AprilTag detector was used in only 3 repos in our count. WPILib’s docs warn that vision on the roboRIO can slow the robot program, so it suits learning more than matches.
