private void setUpSimulation() {

  visionSim = new VisionSystemSim("main"); // a simulated field

  visionSim.addAprilTags(TAG_LAYOUT); // with every 2026 AprilTag on it

  // A pretend camera: 960 x 720 pixels, 90 degree view, 15 frames a second, 50 ms late.

  var props = new SimCameraProperties()

      .setCalibration(960, 720, Rotation2d.fromDegrees(90))

      .setFPS(15)

      .setAvgLatencyMs(50)

      .setLatencyStdDevMs(15);

  visionSim.addCamera(new PhotonCameraSim(camera, props), ROBOT_TO_CAMERA);

}

@Override

public void simulationPeriodic() {

  visionSim.update(drive.truePose()); // where the robot really is, not its estimate

}

VisionSystemSim is a pretend field with every 2026 tag on it. PhotonCameraSim is a pretend camera with a resolution, field of view, frame rate and delay that you choose. Every loop, the sim is told where the robot really is, and it works out which tags the camera would see. Your real PhotonVision code then runs unchanged. That true pose comes from the drivetrain simulator in Deck 10, not from the estimate. PhotonVision’s docs say the sim does not model camera brightness or thresholding. We did not find a simulator in Limelight’s docs. QuestNav’s simulation needs a real headset on the network.
